# React + Tailwind v4 전용 가이드

> ⚠️ 골격 단계 — 첫 v4 프로젝트 시도 시 채울 예정.

`react/_common.md` + `tailwind/_common.md` 와 함께 로드. 이 파일은 **Tailwind v4.x** 프로젝트에만 해당. 프로젝트 `package.json` 의 `tailwindcss` 가 `^4.x` 일 때만 참조.

v3 프로젝트라면 이 파일 **읽지 말고** `v3.md` 참조.
